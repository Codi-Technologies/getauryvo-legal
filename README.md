# Auryvo website

This repository contains the official plain HTML and CSS website for Auryvo:

- `/`
- `/privacy/`
- `/terms/`
- `/support/`
- `/delete-account/`

Natalie Lehman approved the legal copy on October 2, 2026. The approved policies use October 2, 2026 as their effective date.

For local development from the repository root:

```sh
python3 -m http.server 4173 --directory site
```

Then open `http://127.0.0.1:4173/`.

The site is hosted by GitHub Pages at [getauryvo.com](https://getauryvo.com).
